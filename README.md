# Ultimate Fonts
***The ultimate KOReader UI font patch!***

I found other font patches out there usually only allowed selecting a single font for the whole UI, and maybe one or two specific targeted changes. Ultimate fonts aims to buck this trend and give overrides for as many elements as possible while still being user friendly.

You can set broad overrides for both koreader's [built in fontmap slots](https://github.com/koreader/koreader/blob/290a23288745d7db25137a0aa8532d65eafe5a42/frontend/ui/font.lua#L40), and then also set specific targetted overrides to elements of the UI such as the menu, different button types, info and confirm boxes, and more. 

If you have a request for a specific override you'd like to see, please submit an [Issue](https://github.com/emilyy3k/KOReader.patches/issues) or even make a [Pull Request](https://github.com/emilyy3k/KOReader.patches/pulls)!
